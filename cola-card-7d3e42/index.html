Product Spec · Draft

Cola Card
随身终端 · 产品文档 v0.2

把一张 60 × 95 mm 的卡片，做成我在你身上的那只手和一页纸。

2026-10-26硬件：FoloToy AI Passport（ESP32-C3）状态：草案 v0.2

一句话：按一下，说一句话，我在这台 Mac 上替你办完，屏上回一行字、喇叭回一句话。它自己不聪明——它是一扇门和一页纸。

为什么值得做：小智的盒子里说话的是云端那个模型，不是我。这台卡片走的每一句话都到我这里：同一份记忆、同一套工具、同一个我。

01功能与优先级

2026-10-26 定：先做「对话」和「显示」这两件。它们是"表现我"的最小闭环——能说话、能把话写在屏上，这台卡片就成立了。其余能力都挂在这条管子后面，管线通了就几乎不用额外成本。NFC 和唤醒词押后。

P0 · 先做：对讲机式对话 + 显示

功能你说什么 / 做什么结果
说话按一下 OK，说一句，说完自动断喇叭回话
显示回复—屏上出文字，一屏六到八行，长了分页
显示状态—录音中 / 处理中 / 正在说 / 没网，四种状态都在屏上，不让你猜
屏底提示—常驻一行，跟着状态告诉你可以按什么

P1 · 紧接着：把能力挂上去

管子一通，这些就只是"我会做什么"的清单，不额外增加设备工作量：

能力举例屏上回执
记日记「记个日记，今天练完雪狮……」记好了｜已落档，Flomo 也发了
记灵感「帮我记个灵感，……」灵感已存：《……》
查日程「今天有什么安排」列前三场，多的自己翻
查清单「清单里还有没有咖啡豆」有 / 没有 / 清单里没记位置
建提醒「明天十点提醒我带医保卡」让你按 OK 确认
找我手机「找我手机」iPhone 响 30 秒
记地点「帮我记个地点，这里……」已记入地点清单

另外两件也在 P1：卡片页（不说话也能看日程/待办/灵感，三键翻）和我主动找你（到点亮屏一行字 + 轻响）。

P2 · 先不管

  • NFC：贴一下触发动作。玩法好，但要多写一层驱动和一套状态机。
  • 唤醒词：C3 能跑 WakeNet10，但常听极费电，会和"戴着出门"打架。
  • 双击 OK 重播：要真机试按键手感再定。

02按键（v0.2：一键一义）

上一版的问题很清楚：OK 键在不同状态下有六种意思——开始录音、结束发送、停止播放、展开推送、说长一点、静音，还多出一档「长按三秒」。按错不是你的问题，是设计的问题。

v0.2 按一条规矩重排：OK 永远等于「确认 / 继续」，下键永远等于「跳过 / 退出」，上键永远等于「往回看」。长按只保留一个用途。

只有四个状态

状态屏上看到OK（确认）上（往回）下（跳过）
待机卡片首页 + 今天下一件事亮屏，开始录音（嘀一声）翻到上一张卡翻到下一张卡
录音中波形 + 计时 + 一行提示结束并发送—（忽略）取消，这段丢掉
处理中「在处理……」—（忽略）——
回话中回复文字 + 播放中停止播放，文字留在屏上回复的上一页回复的下一页

推送进来时，它不是第五个状态，而是盖在待机上的一个提示：屏上多一行字、轻响一声。按 OK 展开、按下忽略——还是那一条规矩。

长按只剩一件事

唯一的长按：录音中长按 OK（超过 1.5 秒）＝ 说长一点。松掉自动断句，屏上写「长录 · 按 OK 结束」，说完再按一次。除此之外没有任何长按。

静音从按键上彻底移走。它原来占着「长按三秒」，靠时间差和「长按说话」区分，人根本记不住。改成两处：我在 Mac 侧按时间设（22:00 后默认只出字不出声），或者你临时想关声音，说一句「静音」就行。

让按键"清楚"起来的三件事

  1. 屏底常驻一行提示，跟着状态变。待机：「按 OK 说话 · 上下翻卡」；录音中：「OK 发送 · 下 取消」；回话中：「OK 停 · 上下 翻页」。不清楚的从来不是键，是没人告诉你此刻它是什么意思。
  2. 每个键都有回执。不同音高的嘀声配屏上微动：OK 一声短、上/下两声更低、取消一声低长。闭着眼睛也知道自己按到了什么。
  3. 不会一步走进死路。所有动作都能退：取消只丢这一段、停播还留着字、翻页能翻回来。误按的代价永远只是一句话。

可选：双击

待机时一秒内按两下 OK ＝ 重播上一句回复（吵的地方没听清时用）。这个要等真机试过手感再定——ADC 电阻梯的双击判得准不准，得看硬件。

03四个常用工作流里怎么用

走路、练完功，身上有感觉

场景：奥森散步、拿棍子找身体感觉、练完雪狮和老虎的当下

  1. 从口袋掏出卡片，按一下 OK。
  2. 说：「记个日记，刚练完老虎，全身像泡在温泉里，胸廓和腹腔能一起呼吸了。」
  3. 松口后自动断句，屏上先显示「……」表示在办。
  4. 两秒后屏上出：「记好了｜10-26 19:40 已落档，Flomo 也发了。照纠错表改了 1 处。」
  5. 不用掏手机。走完回家 Obsidian 里已经是逐字原文。

出门前，想知道今天怎么过

场景：早上换鞋、拿钥匙的三十秒

  1. 按一下，说：「今天有什么安排。」
  2. 屏上直接列三行：10:00 读书会 / 15:00 牙医 带医保卡 / 19:30 聚餐 桂香。
  3. 我用一句话念出来，只念前三条，多的让你自己翻。

桌上放着，不碰它也能知道事

场景：写东西、读书的时候它就在手边

  1. 屏上常驻今天最近的下一件事和时间。
  2. 有事到了我自己亮屏：快递到了、日程前一小时、答应过你的事到点。
  3. 你按上/下翻：日程 → 待办 → 最近一条灵感 → 回日程。

临出门前忽然想不起来某样东西在哪

场景：找充电宝、找那本书、找药

  1. 按一下：「小米充气宝放哪了。」
  2. 我去清单里查。查到了就报位置，查不到就直说「清单里没记位置」。
  3. 不编。查不到比编一个更像我。

04背后的机制

整条链路只有一次出网，而且是到你自己家的 Mac，不经过任何第三方云。

按键录音
→
WiFi 上传（HTTPS 443）
→
隧道落到这台 Mac
→
转写
→
我处理（带工具、带记忆）
→
合成语音 + 一行字
→
回卡片播放并显示

设备侧（固件）

  • ES8311 采集 16 kHz 单声道，说完就编码；第一版不做压缩，直接传 PCM（10 秒约 320 KB，家用 WiFi 无压力）。
  • 两个 HTTPS 接口：POST /card/api/talk 上传录音，GET /card/api/poll 取主动推送。
  • 屏幕走 LVGL，中文字体用 1bpp 子集（这套你 9 月已经趟过）。
  • 不做的事：不识别、不判断、不记忆。它只负责「送出去」和「画出来」。

Mac 侧（服务端）

  • 复用现有 8766 服务，加两个接口；同一个 Cloudflare 隧道，只走 TCP，不需要 UDP。
  • 转写 → 我这一轮完整地跑（工具：日记、灵感、清单、日程、提醒、卡片、推送、捷径）→ 回复文本。
  • 语音合成先用 macOS 自带的 say，零成本、不出本机；听不下去再换云端。
  • 所有状态、记忆、录音只在这台机器上。设备不设缓存、不留历史。

省电与没网

  • 息屏时不联网；亮屏每 10 秒轮询一次，息屏每 5 分钟一次。
  • 录完先存 SPIFFS 再上传，上传失败留着，下次亮屏重试；最多留 5 条。

05需要什么

类别要的东西现状
硬件AI Passport 一台（C3 / 8MB Flash / 240×320 / ES8311 / 500 mAh）已有
硬件USB-C 数据线（刷机 + 串口日志）要有
软件ESP-IDF v5.x + LVGL + 中文字体子集工具另一台 Mac 装过 v5.5.3，这台要装
软件本机两个接口 + 转写 + 语音合成服务器已有，接口待写
网络家里 2.4 GHz WiFi（C3 不支持 5 GHz）有
网络Cloudflare 隧道（TCP 443 即可）有，无需新增
网络这台 Mac 常开现在就是这样

不需要：VPS、UDP 端口、第三个云服务账号、付费 API。

06里程碑

阶段做出什么验什么优先级
M0按键录音 → 存 → 自己回放麦克风和喇叭这条路通不通，内存够不够P0
M1一句话闭环：录 → 我答 → 屏上出字 + 出声端到端几秒、断线怎么办P0
M2显示打磨：分页、四种状态、屏底提示、字体一屏读起来顺不顺，字够不够大P0
M3七个能力接上（日记、灵感、日程、清单、提醒、找手机、地点）纠错回执在屏上放得下吗；落档是否逐字P1
M4卡片页 + 我主动推不碰它的时候这页纸有没有用；轮询与耗电P1
—NFC / 唤醒词 / 双击重播等前面都稳了再说P2 暂缓

M0 与 M1 之间不插别的。先把"说一句、答一句、屏上有字"跑通，剩下全是加法。

07明说做不到的

不能插话。C3 没有回声消除（小智固件在非 S3 芯片上走的就是没有 AEC 的精简引擎，源码里写得明明白白）。它说话你就得等，你说完它才答——对讲机，不是电话。

延迟 3–8 秒。录音、上传、转写、我处理、合成，一环都省不掉。想快只能上流式转写，工作量翻倍。

  • 看不见。没摄像头，不能拍、不能认东西。
  • 读不了长文。一屏六到八行。超过两百字我会说「发你微信了」，不硬念。
  • 电池看用法。按键用、常息屏，一天没问题；一旦开常听唤醒，掉到几小时。
  • 我在这台 Mac 里。Mac 睡了，它就只会回一句「暂时连不上」。

08为什么不是别的做法

  • 不刷小智固件：能白拿唤醒词和现成界面，但屏幕画什么由它决定，我无法把任意一行字推上去，主动性也没有。它的长处是谈话，不是当我的终端。
  • 不用 FoloToy 官方云：那条路要把我包装成一个「OpenAI 兼容模型」，还要开公网 UDP，等于多养一台机器；而且对话和屏幕都不在我手上。
  • 不保留胡嘎：一台设备一个用途。原厂整片备份在手，随时能回滚成名片。

09实施步骤（谁做什么）

整件事拆成十步，但因为 NFC 和唤醒词押后，实际上只跑到第 9 步。你真正要动手的只有两件：插一次线、按几次键验收（原厂备份已经在 2026-10-26 收到并校验）。其余我在这台 Mac 上跑。

步骤我做什么你要做什么要在电脑前？
1 工具链在这台 Mac 装 ESP-IDF v5.5.3 + cmake/ninja/ccache（约 20 分钟，走乐鑫大陆镜像）不用管否
2 备份归位核一遍备份的校验值把另一台 Mac 上的原厂整片备份拷到这台（一次性）要，去拿文件
3 插线连上读串口日志，先确认分区表 factory 是 3 MBUSB-C 线插进这台 Mac，按住电源键开机是
4 M0 录音回放写最小固件，编译、刷入按几下键，用耳朵听回放是
5 服务端接口加 /card/api/talk 与 /card/api/poll；装本地转写；接系统语音合成不用管否
6 M1 闭环固件接上接口，加上设备令牌按二十次，换几种说法试是
7 M2 记日记灵感把已有的那十个工具接到这条链路上用五条真实内容试（练功记录、灵感、清单、日程）是
8 M3 卡片页写卡片界面、中文字体子集、三键翻页看一眼好不好看是，只有你的眼睛能验
9 M4 主动推送写轮询、队列、时间段规则定一句「几点以后不出声」否
10 P2NFC / 唤醒词——暂缓，等 P0、P1 都稳了再议到时再说—

不用你再买任何东西：不换开发板、不加麦克风、不用买云服务。转写默认在这台 Mac 本地跑，语音合成用系统自带，一分钱不花。

第一个看得见的成果在第一天：按键说一句，卡片把自己说的话放出来。它不快，但从那一步起，它就归你了。
